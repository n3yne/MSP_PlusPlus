# Keyboard shortcuts

[Docs home](README.md) › Keyboard shortcuts

## Tabs and pages

| Shortcut | Action |
|---|---|
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close tab |
| `Ctrl+Shift+T` | Reopen closed tab |
| `Ctrl+Tab` or `Ctrl+PageDown` | Next tab |
| `Ctrl+Shift+Tab` or `Ctrl+PageUp` | Previous tab |
| `Ctrl+1` – `Ctrl+8` | Switch to tab by position |
| `Ctrl+9` | Switch to the last tab |
| `Alt+Left` / `Alt+Right` | Back / forward |
| `F5` or `Ctrl+R` | Refresh active tab |
| `Ctrl+Shift+R` | Refresh active tab, ignoring the cache |
| `Ctrl+Alt+R` | Refresh all tabs |
| `Ctrl+L` | Focus the address bar |
| `Ctrl+F` | Find in page |
| `Ctrl`+mouse wheel, `Ctrl+=` / `Ctrl+-` | Zoom the page in / out |
| `Ctrl+0` | Reset page zoom |

## App

| Shortcut | Action |
|---|---|
| `Ctrl+K` | [Command palette](browser.md#command-palette) |
| `Ctrl+,` | Open Settings |
| `Ctrl+Shift+B` | Show or hide the [side panel](side-panel.md) |
| `Ctrl+Shift+I` | Developer tools (for [troubleshooting](troubleshooting.md)) |

## Notes tab ([Note Backup](plugins/note-backup.md))

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+S` | Save snapshot |
| `Ctrl+Shift+V` | Paste as plain text |

## Password Vault

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+F` | Fill the current page's sign-in from the [Password Vault](plugins/password-vault.md#auto-fill); again within 10 seconds for the next login for that site |
| `Ctrl+Shift+L` | Lock the [Password Vault](plugins/password-vault.md) |

Tab shortcuts work even while you're typing in a page. Plugins list their own keys on their pages, such as the list keys in [Tree Style Tabs](plugins/tree-tabs.md#using-it).
